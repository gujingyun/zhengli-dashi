# 🎮 整理大师 (ZhengLi Master)

一款休闲收纳消除小游戏，玩家通过拖拽将物品放入对应收纳盒，3个相同物品放满后自动消除。

## 游戏玩法

- 拖拽物品到对应类型的收纳盒
- 3个相同物品放满盒子后自动消除
- 在步数用完前清空所有物品即可通关

## 技术栈

- **引擎**: 团结引擎 (Tuanjie Engine) 2022.3
- **语言**: C#
- **发布平台**: 微信小游戏 / 抖音小游戏

## 项目结构

```
Assets/
├── Scripts/          # C# 脚本
│   ├── Core/         # 核心系统
│   ├── Gameplay/     # 游戏玩法
│   ├── UI/           # UI系统
│   └── Utils/        # 工具类
├── Scenes/           # 场景文件
├── Prefabs/          # 预制体
├── UI/               # UI资源
├── Resources/        # 运行时资源
├── Audio/            # 音效
└── Art/              # 美术资源
    ├── Sprites/      # 精灵图
    ├── Animations/   # 动画
    └── Atlas/        # 图集
```

## 开发规范

- 遵循 Unity/C# 编码规范
- 使用 MVC 架构模式
- 所有公共方法需添加 XML 注释
